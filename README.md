# Orange Pi 4A — локальный портал

Единый проект: `/home/orangepi/Documents/local-portal`.

- `dashboard/` — главная страница, LED-шаблон и общие изображения/стили.
- `camera/www/` — страница видеопотока и исходные примеры MJPG-streamer с лицензией.
- `terminal/index.html` — встроенный клиент установленного ttyd с кнопкой возврата.
- `led-panel/` — Flask API, LED-контроллер, список установленных Python-зависимостей.
- `led-service/` — исходный автономный эффект светодиодной ленты.
- `data/gestures.json` — существующие записанные жесты.
- `scripts/` — установка, откат и запуск камеры.
- `systemd/` — настройки сервисов с подстановкой `@PROJECT_DIR@` при установке.

## Установка на этой OrangePi

```bash
sudo python3 /home/orangepi/Documents/local-portal/scripts/install.py
```

Установщик сохраняет прежние каталоги и конфигурацию в закрытой папке
`/var/backups/local-portal-*`, переносит готовое Python-окружение внутрь
проекта, а на прежних путях создаёт символические ссылки. Перенос не требует
переустановки 817 МБ зависимостей. Старые пути окружения продолжают работать.
Системные службы получают отдельные drop-in настройки. Логин и пароль ttyd
сохраняются из существующей службы и не записываются в Git.

LED-сервис `myapp` был выключен и отключён от автозапуска. Установщик запускает
его и включает автозапуск, чтобы ссылка на LED-панель работала. При открытии страницы LED-модуля фоновый эффект продолжает работать.
LED-приложение получает управление только после явной команды пользователя.
После выхода оно прекращает запись кадров, освобождает SPI и запускает
`led-bouncing.service`. При обрыве связи управление возвращается через 30 секунд.
Просматривающие вкладки не удерживают ленту: управление возвращается после
выхода последней вкладки, отправлявшей команды. Фоновый сервис сразу запускает
бегущий светодиод, без стартовой красной заливки. При установке веб-терминал и видеопоток кратковременно перезапускаются.

Адрес главной: `http://192.168.12.1:57575/`. Ссылки используют текущий адрес
устройства, сохраняя порты: терминал 8000, камера 8080, LED 3000.
Все переходы происходят в той же вкладке. На каждом сайте есть «На главную».
Клиент ttyd сохранён без изменений его WebSocket-протокола; добавлены значок
вкладки, верхняя навигация и отступ для неё. Исходники сторонних библиотек
MJPG-streamer и бинарный файл ttyd остаются установленными зависимостями.

## Откат

Установщик печатает точную команду:

```bash
sudo python3 /home/orangepi/Documents/local-portal/scripts/install.py --rollback /var/backups/local-portal-ИМЯ_КОПИИ
```

Откат возвращает исходные каталоги, Python-окружение, конфигурацию и состояния
служб. При ошибке установки откат выполняется автоматически.

## Git

Репозиторий инициализирован на ветке `main`, без коммитов, remote и push.
`venv`, кэши, логи и локальные секреты исключены из Git. Резервные копии хранятся
вне проекта. После входа в Git-аккаунт можно проверить `git status`, создать
базовый коммит и настроить удалённый репозиторий.

Разработчики сайта: Кадир Тагиров, Никита Ватолин, Максим Мухамадияров.

Проверка управления LED: `python3 -m unittest discover -s tests -v` (без оборудования).
